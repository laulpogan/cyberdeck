Motion is a
measurement

Every animation here is a function of a number some producer actually supplied. When that number is missing, nothing moves.

Most sci-fi interface libraries ship shapes — clip-path corners, scanlines, a neon palette. Point one at a feed that died an hour ago and it sweeps, pulses and counts exactly as it did when the feed was alive, because nothing in it knows the difference. The dangerous case is not the outage. It is the panel that keeps moving through the outage, because a moving panel is how a person decides not to look closer.

The nine kinds

Each panel is the same component twice. On the left it was given evidence, so it moves. On the right the evidence is missing — and it does not fall back to a default, a spinner, or a house tempo. It refuses, and prints why. The right-hand side is the library.

What refusal looks like

These are not error states. Each is the correct rendering of a situation the data is actually in.

SituationWhat happensReason written into the markup
A route delivered nothingThe path does not draw itselfnothing travelled this path
The feed went staleClock and pulse both stopthe clock stopped when the feed did
Nobody counted the populationThe stagger is refusedpopulation was not counted
A quantity was never measuredThe bar does not grow to zeroquantity was not measured
A poll is overdueThe cycle refuses to wrappoll is overdue

That last one is the whole design in miniature. A poll due forty seconds ago that has not landed is the finding. An indicator that quietly wrapped and started again would erase it.

A mark is an attribute

Nothing else. No component ships animation code, which is what lets the honesty be tested without a browser — and lets React, a template, or a server in another language emit the identical contract without three implementations drifting apart.

// evidence present
trace(route.delivered, { cite: 'routes[].delivered' })
// → { 'data-motion': 'trace', 'data-cite': 'routes[].delivered' }

// evidence absent — not a fallback, a declaration
trace(false, { cite: 'routes[].delivered' })
// → { 'data-motion': 'still',
//      'data-still-reason': 'nothing travelled this path' }
// React spreads one directly, because the keys are already data-*
<path {...trace(r.delivered, { cite: 'routes[].delivered' })} />

Press Motion off above. Every kind rests at the geometry the markup already declared, so cancelling is settling — not a second design, and not a page frozen part-way into an entrance. The operator's system preference, the toggle, and a vendor bundle that fails to load all land on the identical page.

Every panel on this page is built by calling the real library and printing whatever comes back, refusals included — so it cannot drift from what it advertises. Runtime, marks and palette are inlined here verbatim.
