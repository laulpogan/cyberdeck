Motion Is a Measurement

Hive · the motion vocabulary

Motion is a
measurement

An operations console that never moves makes you check whether it has frozen, and the checking is the cost. But motion is the easiest lie a dashboard can tell — a sweep reads as scanning, a pulse reads as traffic, and a setInterval will draw both over a payload that has not changed since Tuesday. So every animation here is a function of a number some producer actually supplied, and when the number is missing the animation is refused rather than defaulted. Nine kinds, each shown beside its own refusal. Everything on this page runs the engine and the runtime the product ships.

A

ARRIVE

Did this change, and does anybody know when?

an observed timestamp

Things that changed enter. Things that did not, do not move — so movement carries the whole signal of look here. “It probably just changed” would fire on every reload and teach an operator that movement means nothing.

B

DECAY

How old is this, really?

a measured age against a stated window

The fade is the age. A value measured nine seconds into a twelve second window arrives three quarters settled — you can read staleness off the motion before you read the number. Past the window it is simply old, and old values sit still.

C

COUNT

How many of these are there?

an index inside a real count

The wall reveals cell by cell in the order the board was counted, so the eye crosses it the way the crush intends rather than being handed the finished field with the bleeding cells already located. A board nobody enumerated gets no wall at all — an empty grid is a measured zero, and this is the component where that lie would be least survivable.

D

LEVEL

How much of it?

a measured quantity and its ceiling

The growth is not decoration over a number — it is the number. Which is exactly why an unmeasured quantity may not grow to zero: on this console a bar at nought and a bar nobody filled in must never look alike, and motion is the loudest way to make them look alike.

E

ELAPSED

How long ago?

a measured duration on a live source

The only kind that keeps a number moving. A wait of five hours measured three seconds ago is five hours and three seconds now, so freezing it at the render was the less truthful of the two options. On a feed gone stale the clock stops — a counter still ticking claims somebody is still watching.

F

TRACE

Did something actually travel this?

the fact that something travelled it

The kind the drawings needed, and the sharpest refusal in the set. Watching a line travel from origin to destination is the most convincing way a console can say a thing arrived — so the corridor draws as far as the door that held and the six behind it stay dashed and still, and not one of these three strands draws at all, because not one of them delivered.

G

TRAFFIC

Is anything happening right now?

a live source and a measured interval

The single ambient loop the spec allows, breathing at the producer’s own interval rather than a house tempo scaled by a reading. Watch the cadence tighten and you are watching the measured wait tighten. A pulsing panel over frozen data is the lie in its purest form.

H

CYCLE

Is this feed still being polled?

a measured poll interval and position in it

The radar sits at the angle its own freshness put it and goes round once per poll interval, so what you are watching turn is the poll you are waiting for — the one thing a radar drawn as a still picture cannot say. Nothing about it can be faked, because the period is the period. Beside it, the same instrument on a feed that is not live: same dial, same rings, no wedge, and it says which. A sweep that quietly started another lap would have hidden that.

I

INTENT

Did the operator just do something?

none — the operator is the producer

The one kind that never has to prove anything. Written in CSS rather than the runtime, so hover and focus keep responding even when the script never parses — an interface that stops answering feels broken in a way a missing flourish does not.

Stillness is declared

Every dashed magenta cell above is a real refusal carrying a real reason, written into the markup by the same functions that write the moving ones. That matters because a region with no motion mark and a region whose mark was forgotten render identical HTML — so the correct one says why it is not moving, and the test suite can tell them apart.

The engine

Four candidates, built against the real surface and measured rather than taken from vendor claims. The deciding column is mechanism: Motion and native WAAPI hand real Animation objects to the browser, so an element’s resting appearance stays whatever the server rendered. The other two write inline style from a JS tick and would have needed a second description of every rest state.

Off is the rendered page

Every kind rests at the geometry the server already drew, so cancelling is settling. Motion off above, the operator’s system preference, a ?still=1 in the URL and a vendor bundle that fails to load all land on the identical page — not a second design, and not a page frozen part-way into an entrance. The review script proves it by comparing the markup before and after.
