# The substitution matrix — the six patterns that matter

A ranking of the fifty motifs by how many operator roles each one serves at once,
rather than by how good it looks. It was written against four reference products
and their abilities, with every substitute's producer status checked against live
gateways rather than assumed.

Full page, including the ability-by-ability table and the mobile cut:
[`pages/the-substitution-matrix.html`](pages/the-substitution-matrix.html).

## Verdict vocabulary

The vocabulary is the useful part, because it separates "we could build this" from
"the data exists to build this honestly".

| Verdict | Meaning |
| --- | --- |
| SUB NOW | The producer supplies the data today |
| SUB LATER | The pattern is right, the producer is missing |
| GATED | Blocked on an authority or mutation seam that does not exist yet |
| DON'T SUB | Stays theirs; out of scope by law |
| OUR ADVANTAGE | They lack it entirely |

## The six

**1. Dominator authority states.** A control without a grant renders as inert
glass naming the authority it lacks. One pattern serving governance, orchestration,
chat control and mobile at once. It kills the fake-retry class permanently and
makes a verb surface self-documenting. This is the pattern that makes an
agent-facing interface trustworthy enough to hand to a chat client.

**2. Tape and shutter.** One queue of human decisions across every harness, with a
shutter that opens only for the item that needs a person and leaves everything
else as one quiet line. Comparable products either ping per session or have no
human channel at all.

**3. Cassette rack and tape scrub.** The session-truth spine. Not terminals —
attempts. Durable work identity across retries, failures rewinding visibly, and the
adopted take playing clean. This is what a chat history becomes once it grows
receipts.

**4. Quickhack command ladder.** Every operation listed with its authority price
and expected wait, disabled rungs naming the missing grant. One component covers
retry, reassign, drain, abandon and salvage, and it composes with #1 as its
rendering rule.

**5. Killmail receipt.** Cost was withheld by the gateway, honestly — so the
receipt ships anyway with an UNPRICED cost class, and lights up in place when
charge records arrive. Also the unit that makes provider comparison possible.

**6. Turn() batch commit.** Queue bounded commands against an authority budget,
review the plan, commit once, get one receipt set. Gated: no mutation route exists
until an authenticated retry seam lands. A disabled plan bar is honest; a live one
that fakes is not.

## The pattern behind the ranking

Five of the six are refusals wearing different clothes. The rank order is not
aesthetic — it tracks how many roles a single honest refusal can serve before it
has to be specialised.
