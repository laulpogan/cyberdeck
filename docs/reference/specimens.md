# The specimen drawer — 50 motifs

Fifty interface motifs, each drawn as a working vignette, each naming the work it
was lifted from and the operator role it serves. The Idea Bank names the motifs;
the drawer renders them.

Rendered page: [`pages/the-specimen-drawer.html`](pages/the-specimen-drawer.html).
Every tile there is canvas, drawn from sample data, stamped CONCEPT — a specimen
for peeling, not a canonical surface. Seven families, and the family names are the
same seven the library ships as component groups.
