# Published artifacts — the index

Twenty-eight pages were published as Claude artifacts across this work. Twelve
carried the design research for this library and now live in the repository as
files; the rest are listed for provenance.

A preserved copy is the artifact's own HTML with the host frame runtime stripped
and nothing else edited. Each file names its source URL in a comment at the top.
The pages are self-contained apart from Google Fonts, so they open from the file
system.

## Not preserved

**Everything So Far** —
[artifact](https://claude.ai/code/artifact/8fbfc9c8-5519-48cf-bdea-567a17d1a35a).
A contact sheet of 36 photographed frames across five pages, 3.3 MB of it inline
base64. Preserving it would mean committing the images, and the same frames exist
as PNGs on `motion/vault-gauntlet` under `vault/film/`. Its own tally is worth
recording: 50 specimens, 77 total components, 3 built in this library at the time
(gauge, river, globe), 50 portable, 15 canvas-only rebuilds.
