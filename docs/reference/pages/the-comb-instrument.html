What the pattern actually is

Not a chart. An instrument for reading a population.

Strip the hexagons away and the pattern underneath is simple: take a set of things that all have the same shape, give each one cell, and drive that cell from a measurement that is true right now. The hexagon matters only because cells that share edges read as one field rather than as a grid of separate objects — the eye gets a texture instead of a list.

Which means the interesting question is never "should this be hexagons". It is which population, and which measurement. Change either and you have a different instrument built from the same parts.

Where this sits in the field

Datadog Host Map

The mature version of this exact pattern. Each host is a hexagon, colour is a metric (CPU by default, green to red), nodes sharing a tag cluster into hexagonal groups, and a click zooms into that host's integrations.

Verdict: we converged on it independently, including the grouping. Their cells are hosts — a population that barely changes.

Calm technology

The design discipline for information that lives in the periphery: glanceable, no modals, no alarm walls. There is now a Calm Tech Institute certification with a published 2025 product list, so this is a maintained standard rather than a 1995 essay.

Verdict: this is the theory behind "changing with system status". It also warns why an all-red field failed — alarm colour spent on the ordinary state.

Agent observability, 2026

The category is trace-first: timelines, span graphs, token counters, OpenTelemetry GenAI conventions. Its own practitioners name the failure — reconstructing a swarm means replaying many concurrent agents, and "five concurrent agents producing five concurrent traces with shared state mutations is unreadable."

Verdict: the whole field is building better microscopes. Nobody is building the wide shot.

Traces answer what did this agent do. At ninety concurrent agents that question is unanswerable and also the wrong one. The comb answers what is the colony doing — and that instrument, applied to work rather than to hosts, is the thing the 2026 field does not have.

Other populations, other encodings

Grouped by which part you swap. Each names the signal it rides on, because a cell property with no measurement behind it fails the vision doc and cannot be filed.

what a cell is
A cell is a systemd unit

165 user timers run this fleet and nothing shows them at once. Colour by last exit status, brightness by time since it completed. Tonight's failures kept coming from here and it has no view.

signal · systemctl show ExecMainStatus
A cell is a card, not just a worker

Queued cards are unbuilt comb, blocked cards stripe, cards done today are spent comb fading over the day. This is what makes the comb the kanban rather than a view of it.

signal · the board
A cell is a branch at the merge gate

Colour by gate verdict, brightness by age. Turns the merge queue from a log line into a place you look at.

signal · gate cache (branch sha, trunk sha)
A cell is a repo file

Churn heat over a week. Shows which files the swarm keeps fighting over — which is to say, where two writers will collide next.

signal · git log --numstat
A cell is a lens

One hex per lens, brightness by cards landed. The swarm's steering wheel drawn as a comb, so re-pointing it is something you see rather than reason about.

signal · board history
A cell is an hour

A contribution comb over the last week, brightness = commits landed that hour. Answers "was last night any good" without reading a log.

signal · git log --since
A cell is an open defect

Every OPEN line in the gate-failure ledger as a field you cannot look away from. Currently that ledger is only read when the scoper remembers to.

signal · state/gate-failures.md
A cell is a host

Datadog parity for the four machines and the engines: colour by GPU utilisation, brightness by queue depth. The one case where the prior art is a spec.

Swap the encoding

what a cell says
A sparkline inside each cell

Its own last hour of log growth, drawn in the hex. Separates "quiet because queued" from "quiet because stuck" without opening anything — the exact confusion that cost hours tonight.

signal · sampled log sizes
Nested comb

A hex that contains its own comb. Click a lens and it expands into that lens's workers, in place. Uber's H3 hierarchical hex index is the reference.

signal · existing clustering
Size is spend

Cell size by tokens burned, colour still state. An expensive agent becomes visibly expensive, which is the only way spend gets felt rather than audited.

signal · usage sensor
Ghost cells

A finished worker leaves a fading trace for an hour, so you can see where effort went this evening without a report.

signal · completed_at
Notches for reclaims

A card reclaimed three times looks different from one on its first attempt — the difference between healthy and doomed, currently invisible.

signal · retry counter

Make it ambient

the comb reacting to system state — the axis worth the most
Field temperature

The ground shifts with engine saturation. When the engines are sixty deep, quiet cells are queued and not stalled, and the field should say so ambiently instead of on another page. Already carded.

signal · vllm num_requests_waiting
The favicon is one hexagon

Coloured by the worst state on the board. Fleet state readable from a browser tab in another window — the cheapest ambient display available, and it costs one canvas element.

signal · board totals
The hum

Audio ambient. Pitch tracks throughput, a dropped note marks a failure. Bees, and genuinely peripheral — you notice a room going quiet without looking at anything.

signal · commits landed, failures
Full-bleed screensaver

The comb with no chrome, legible across a room, for a spare monitor or a TV on the wall.

signal · unchanged
Statusline comb

The field compressed to one line, one block per lens, shaded by activity. Puts the fleet in every shell prompt you open.

signal · /api/fleet
Wallpaper, regenerated

Desktop background rebuilt each minute from the live comb. Ambient by construction: you see it whenever you clear your windows.

signal · unchanged
One hex to phone or watch

Colour is fleet state. Answers "is it still running" without opening anything at all.

signal · board totals

Add time, and add control

the comb as a record, and as an instrument
Scrub back through the comb

The SQLite history is already in the repo. Watching the swarm build itself is the demo; replaying a bad hour is how you diagnose one.

signal · existing history slices
Comb diff

Two moments side by side, cells that changed state highlighted. "What changed while I slept" as a picture rather than a digest.

signal · two history slices
Timelapse export

A night rendered to a twenty-second video. The artefact you would actually show someone.

signal · history
Right-click a cell to act

Dispatch, reclaim, peek. The moment this lands the comb stops being read-only and starts being the control surface.

signal · hermes CLI
Drag-select a region

Act on all of it at once. Bulk reclaim of a stuck lens without opening a terminal.

signal · hermes CLI
Generalise the renderer

Point it at any JSON array plus a state field and a recency field, get a comb. The fleet is not the only population with this shape — and the wide shot is the instrument the field is missing.
