The Six That Matter

ranked by usefulness across all five pillars · not by spectacle

1 · Dominator authority statesPsycho-Pass → every surface

The one pattern that serves every pillar at once. Paperclip's governance becomes pixel law: a control without a grant renders as inert glass naming the missing authority. It kills the fake-retry class permanently, makes the orchestrator's verb surface self-documenting, and is what makes an agent-facing UI trustworthy enough to hand to AionUI-style chat control.

SERVES: governance · orchestrator · chat control · mobile (fewer, truer buttons)

The metaharness value proposition in one strip: one queue of human decisions across every harness — Claude Code, Codex, goose, whatever Kanpai drives. Scape pings per-session; Paperclip has no human channel at all. The Telegraph is the consolidation. All data present today.

SERVES: metaharness core · Paperclip's missing human board · THE mobile surface
3 · Cassette rack + VHS scrubKatana ZERO / GitS → Thread + River

The session-truth spine. Scape shows you terminals; this shows you attempts — the durable work identity across retries, with failures rewinding visibly and the adopted take playing clean. Attempts-to-5 and the 9-kind event vocabulary are in the live payload now. This is what AionUI's chat history becomes when it grows receipts.

SERVES: session workbench · orchestrator retry story · post-mortems
4 · Quickhack command ladderCyberpunk 2077 → orchestrator verbs

The generic pattern for every Kanpai operation: commands listed priced in authority and expected wait, disabled rungs naming the missing grant. One component covers retry, reassign, drain, abandon, salvage — the whole orchestrator verb set — and composes with #1 as its rendering rule.

SERVES: orchestrator · governance · mobile (a ladder thumbs well)
5 · Killmail receiptEVE Online → cost control seed

Cost is WITHHELD by the gateway today — honestly. The killmail starts the economics anyway: every lost attempt gets an immutable receipt with fit (model/profile), damage (proof state), and cost class (UNPRICED — subscription pool is a truthful value). When Salud supplies charge records, the cost field lights up in place. This is also the provider-comparison unit AionUI never had.

SERVES: cost control · provider adapter · manager learning loop
6 · Turn() batch commitTransistor → orchestrator batch ops

Queue bounded commands against an authority budget, review the whole plan, commit once, one receipt set. This is Omnigent-class orchestration made honest — and it is gated: no mutation route exists until the authenticated task.retry seam lands. Design it now, wire it when Kanpai exposes the ops. A disabled plan bar is honest; a live one that fakes is not.

SERVES: orchestrator · budget ceilings · the approve-from-phone dream, safely

The Mobile Doctrine

the phone is the Telegraph, full stop · everything else is a read-only card one tap deep

The Snow Crash gargoyle is the failure mode: an operator drowning in feeds. The phone cut refuses it. One surface — the decision queue with motion-tracker cadence — plus push on algedonic class only. Each decision is a card: blocker, consequence of waiting, evidence receipt, and the command ladder with grants honestly rendered. Approve/defer/snooze thumb from the armrest, Cybersyn big-button class, 44px floors. The Field, River, and Organism do not ship on the phone; a tapped card deep-links the desktop. When the mutation seam lands, the phone approves through the same ceremony as the desk — never a lighter one.
