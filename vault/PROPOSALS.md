# Proposals — motion the catalog found that nobody commissioned

The registry has 51 components and they were chosen before the harvest started. Harvesting
turns up behaviour that plainly means something and has nowhere to live: an instrument
whose motion carries information, a transition that does real work, a convention that
recurs across unrelated sources. Those land here.

This file is a queue for a person. Nothing in it is a component, and an agent never
promotes an entry. The bar for adding one:

- **A name and a claim.** What the motion is, and what it would tell an operator. A motif
  with no informational job is decoration, and this library does not ship decoration.
- **A measurement, or an honest absence.** Duration, easing or loop period with its evidence
  tier, or a statement that no source has yet yielded one.
- **Two independent sources.** One occurrence is a style choice. Two unrelated ones is a
  convention, and a convention is what a component encodes.
- **What it would bind.** The cybernetics canon in `docs/reference/cybernetics-canon.md`
  says what obliges a component to behave a certain way. An entry that binds nothing is a
  picture, not a control.

Cap additions at three per pass. A queue that grows faster than it is read is a backlog
nobody trusts.
